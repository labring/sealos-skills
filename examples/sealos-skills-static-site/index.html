Beyond “it deployed”

交付，不止是
推一个镜像。

Sealos Skills 把部署拆成可验证的工程流程。Agent 不只生成 YAML，还会确认入口、网络、日志、数据状态与完整资源足迹，直到应用真的可用。

01 / ASSESS

先判断，再动手

识别 Web、Worker、定时任务与静态站点；对桌面应用、CLI、库和混合仓库保持 fail-closed。

02 / PREPARE

自动补齐部署产物

复用镜像或生成 Dockerfile，把 Compose 与运行时语义转换为符合 Sealos 约束的模板。

03 / CONNECT

云数据库与 S3

发现真实依赖，创建并接入数据库或私有对象存储，同时把凭据留在安全边界内。

04 / SHIP

本地与 Sandbox 双路径

本地使用 Docker buildx；非交互 Sandbox 使用命名空间内 Kaniko，保持同一交付契约。

05 / VERIFY

Runtime Truth Pass

检查 Launchpad 公网、真实 App URL、登录流程、日志、Events、端点与资源足迹。

06 / EVOLVE

原地更新，而非重来

记录部署状态，后续自动识别 Update 模式，完成镜像切换、滚动验证与失败回滚。

A deterministic path
