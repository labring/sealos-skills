<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Physical inventory -> explicit host arrays | A missing or unexpected path changes the set of capabilities a host can install. |
| Codex version -> secondary metadata | Projection versions can influence install, archive, and release identity. |
| Canonical files -> Qoder ZIP | Packager inputs become an imported host bundle and can accidentally duplicate or omit behavior. |
| Pointer manifest -> host loader | Codex, local marketplace, and OpenClaw source paths control which canonical tree is loaded. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Tampering | Explicit plugin and marketplace arrays | high | mitigate | Derive expected paths from immediate physical entries, require exact set equality, and mutate each surface in temporary fixtures. |
| T-07-05 | Tampering | Version-bearing projections | high | mitigate | Load one canonical Codex version, compare every secondary field, and test both canonical and secondary drift. |
| T-07-06 | Spoofing | Codex, local marketplace, and OpenClaw pointers | high | mitigate | Resolve pointer targets inside the repository, require the known symlink/source/command values, and reject broken or redirected paths. |
| T-07-07 | Information Disclosure | Qoder archive output | medium | mitigate | Inspect a temporary archive with standard-library `zipfile`, verify canonical members, and keep generated packages outside the repository. |
</threat_model>
